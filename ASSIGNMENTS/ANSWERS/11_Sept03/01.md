### Solutions to Assignment 1

#### Q1. Find the total number of employees in each department.
```sql
SELECT department, COUNT(*) AS total_employees 
FROM employees 
GROUP BY department;
```

#### Q2. Find the average salary of employees in each job role.
```sql
SELECT job_role, ROUND(AVG(salary), 2) AS average_salary 
FROM employees 
GROUP BY job_role;
```

#### Q3. Find the highest salary in the IT department.
```sql
SELECT MAX(salary) AS highest_it_salary 
FROM employees 
WHERE department = 'IT';
```

#### Q4. Find the lowest salary among all employees.
```sql
SELECT MIN(salary) AS lowest_salary 
FROM employees;
```

#### Q5. Count the number of employees who joined after January 1, 2023.
```sql
SELECT COUNT(*) AS employees_joined_after_2023 
FROM employees 
WHERE hire_date > '2023-01-01';
```

#### Q6. Find the total salary paid in each department.
```sql
SELECT department, SUM(salary) AS total_salary_paid 
FROM employees 
GROUP BY department;
```

#### Q7. Find the job role that has the highest total salary payout.
```sql
SELECT job_role, SUM(salary) AS total_payout 
FROM employees 
GROUP BY job_role 
ORDER BY total_payout DESC 
LIMIT 1;
```

#### Q8. Find the average salary of employees who joined after 2022.
```sql
SELECT ROUND(AVG(salary), 2) AS average_salary 
FROM employees 
WHERE hire_date > '2022-12-31';
```

#### Q9. Find departments where the total salary exceeds 10,000.
```sql
SELECT department, SUM(salary) AS total_salary 
FROM employees 
GROUP BY department 
HAVING total_salary > 10000;
```

#### Q10. Find the department with the highest number of employees.
```sql
SELECT department, COUNT(*) AS employee_count 
FROM employees 
GROUP BY department 
ORDER BY employee_count DESC 
LIMIT 1;
```


---

### Solutions to Assignment 2

#### Q1. Find the total number of students in each class.
```sql
SELECT class, COUNT(*) AS total_students 
FROM students 
GROUP BY class;
```

#### Q2. Find the highest marks scored in Math.
```sql
SELECT MAX(marks) AS highest_math_marks 
FROM students 
WHERE subject = 'Math';
```

#### Q3. Find the average marks in each subject.
```sql
SELECT subject, ROUND(AVG(marks), 2) AS average_marks 
FROM students 
GROUP BY subject;
```

#### Q4. Find the total number of students who scored above 80.
```sql
SELECT COUNT(*) AS students_scored_above_80 
FROM students 
WHERE marks > 80;
```

#### Q5. Find the number of students who took the exam in each month.
```sql
SELECT 
    MONTH(exam_date) AS exam_month,
    MONTHNAME(exam_date) AS month_name,
    COUNT(*) AS total_students 
FROM students 
GROUP BY exam_month, month_name 
ORDER BY exam_month;
```

#### Q6. Find the subject where students scored the highest average marks.
```sql
SELECT subject, ROUND(AVG(marks), 2) AS average_marks 
FROM students 
GROUP BY subject 
ORDER BY average_marks DESC 
LIMIT 1;
```

#### Q7. Find the student who scored the lowest marks in Science.
```sql
SELECT name, marks 
FROM students 
WHERE subject = 'Science' 
ORDER BY marks ASC 
LIMIT 1;
```

#### Q8. Find the number of students in each class who scored more than 85.
```sql
SELECT class, COUNT(*) AS students_above_85 
FROM students 
WHERE marks > 85 
GROUP BY class;
```

#### Q9. Find the average marks for each subject where the average is above 80.
```sql
SELECT subject, ROUND(AVG(marks), 2) AS average_marks 
FROM students 
GROUP BY subject 
HAVING average_marks > 80;
```

#### Q10. Find the student who scored the highest marks overall.
```sql
SELECT name, class, subject, marks 
FROM students 
ORDER BY marks DESC 
LIMIT 1;
```

## Assignment 3: Employee Analysis (GROUP BY + HAVING / ORDER BY)

*Uses `employees` table from Assignment 1.*

#### Q1. Find the total number of employees in each department and display only those departments having more than 2 employees. (GROUP BY + HAVING)
```sql
SELECT department, COUNT(*) AS total_employees 
FROM employees 
GROUP BY department 
HAVING COUNT(*) > 2;
```

#### Q2. Find the total salary paid in each department and display the results in descending order of total salary. (GROUP BY + ORDER BY)
```sql
SELECT department, SUM(salary) AS total_salary_paid 
FROM employees 
GROUP BY department 
ORDER BY total_salary_paid DESC;
```

#### Q3. Find the job role that has the highest total salary payout, displaying only roles where total salary is above 10,000. (GROUP BY + HAVING + ORDER BY)
```sql
SELECT job_role, SUM(salary) AS total_salary_payout 
FROM employees 
GROUP BY job_role 
HAVING total_salary_payout > 10000 
ORDER BY total_salary_payout DESC 
LIMIT 1;
```

#### Q4. Find the average salary of employees who joined after 2022, displaying only job roles where the average salary is above 4500. (WHERE + GROUP BY + HAVING)
```sql
SELECT job_role, ROUND(AVG(salary), 2) AS average_salary 
FROM employees 
WHERE hire_date > '2022-12-31' 
GROUP BY job_role 
HAVING average_salary > 4500;
```

#### Q5. Find departments where the total salary exceeds 10,000 and order the results in ascending order of department name. (GROUP BY + HAVING + ORDER BY)
```sql
SELECT department, SUM(salary) AS total_salary 
FROM employees 
GROUP BY department 
HAVING total_salary > 10000 
ORDER BY department ASC;
```

## Assignment 4: Student Analysis (GROUP BY + HAVING / ORDER BY)

*Uses `students` table from Assignment 2.*

#### Q1. Find the average marks in each subject and display only subjects where the average is above 80. (GROUP BY + HAVING)
```sql
SELECT subject, ROUND(AVG(marks), 2) AS average_marks 
FROM students 
GROUP BY subject 
HAVING average_marks > 80;
```

#### Q2. Find the total number of students in each class and order them by class in descending order. (GROUP BY + ORDER BY)
```sql
SELECT class, COUNT(*) AS total_students 
FROM students 
GROUP BY class 
ORDER BY class DESC;
```

#### Q3. Find the subject where students scored the highest average marks, displaying only subjects where the average is above 85. (GROUP BY + HAVING + ORDER BY)
```sql
SELECT subject, ROUND(AVG(marks), 2) AS average_marks 
FROM students 
GROUP BY subject 
HAVING average_marks > 85 
ORDER BY average_marks DESC 
LIMIT 1;
```

#### Q4. Find the student who scored the highest marks overall. (ORDER BY + LIMIT 1)
```sql
SELECT name, class, subject, marks 
FROM students 
ORDER BY marks DESC 
LIMIT 1;
```

#### Q5. Find the number of students in each class who scored more than 85, displaying only classes with more than 2 such students. (GROUP BY + HAVING)
```sql
SELECT class, COUNT(*) AS students_above_85 
FROM students 
WHERE marks > 85 
GROUP BY class 
HAVING students_above_85 > 2;
```
