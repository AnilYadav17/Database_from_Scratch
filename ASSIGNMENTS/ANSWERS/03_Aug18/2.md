# Assignment 2 — Library Management System

## 1. Create Database
```sql
CREATE DATABASE library_management;
USE library_management;
```

## 2. Create Tables

### `books` Table
```sql
CREATE TABLE books (
    book_id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL,
    author VARCHAR(150) NOT NULL,
    isbn CHAR(13) UNIQUE,
    price DECIMAL(8, 2) UNSIGNED,
    available_copies INT UNSIGNED DEFAULT 1,
    category VARCHAR(50),
    publication_date DATE,
    is_available BOOLEAN DEFAULT TRUE,
    description TEXT
);
```

### `students` Table
```sql
CREATE TABLE students (
    student_id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    student_name VARCHAR(100) NOT NULL,
    enrollment_no VARCHAR(20) UNIQUE NOT NULL,
    age TINYINT UNSIGNED,
    gender ENUM('Male', 'Female', 'Other'),
    date_of_birth DATE,
    contact_number VARCHAR(15),
    email VARCHAR(100) UNIQUE,
    is_active BOOLEAN DEFAULT TRUE,
    registration_date DATE
);
```

### `transactions` Table (Book Issue/Return)
```sql
CREATE TABLE transactions (
    transaction_id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    student_id INT UNSIGNED,
    book_id INT UNSIGNED,
    issue_date DATE NOT NULL,
    expected_return_date DATE NOT NULL,
    actual_return_date DATE,
    fine_amount DECIMAL(6, 2) UNSIGNED DEFAULT 0.00,
    is_returned BOOLEAN DEFAULT FALSE,
    remarks VARCHAR(255),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (book_id) REFERENCES books(book_id)
);
```
