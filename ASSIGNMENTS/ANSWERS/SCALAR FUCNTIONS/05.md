# Assignment 05 — SQL Date & Time Functions

## Scenario Overview
A company maintains employee and attendance information in a single table: `employee_attendance`. The HR department analyzes employee **joining dates, birth dates, project dates, attendance dates, login times, logout times, and working duration** using MySQL Date & Time functions.

---

## Table Structure & Setup

### 1. Create Table: `employee_attendance`
```sql
CREATE TABLE employee_attendance (
    attendance_id INT PRIMARY KEY AUTO_INCREMENT,
    employee_id INT NOT NULL,
    employee_name VARCHAR(50) NOT NULL,
    department VARCHAR(30) NOT NULL,
    city VARCHAR(30) NOT NULL,
    date_of_birth DATE NOT NULL,
    joining_date DATE NOT NULL,
    project_start_date DATETIME NOT NULL,
    attendance_date DATE NOT NULL,
    login_time DATETIME NOT NULL,
    logout_time DATETIME NOT NULL,
    salary DECIMAL(10,2) NOT NULL,
    attendance_status VARCHAR(20) NOT NULL
);
```

### 🏆 Q50. Final HR Attendance Report
Prepare a complete attendance report containing:
* Employee Name
* Department
* Attendance Date
* Day Name
* Login Time
* Logout Time
* Working Hours
* Working Minutes
* Attendance Status
* Joining Date
* Years of Experience

```sql
SELECT 
    employee_name,
    department,
    DATE_FORMAT(attendance_date, '%d %M %Y') AS attendance_date,
    DAYNAME(attendance_date) AS day_name,
    TIME(login_time) AS login_time,
    TIME(logout_time) AS logout_time,
    TIMESTAMPDIFF(HOUR, login_time, logout_time) AS working_hours,
    TIMESTAMPDIFF(MINUTE, login_time, logout_time) AS working_minutes,
    attendance_status,
    DATE_FORMAT(joining_date, '%d-%m-%Y') AS joining_date,
    TIMESTAMPDIFF(YEAR, joining_date, CURDATE()) AS years_of_experience
FROM employee_attendance
ORDER BY attendance_date DESC, employee_name ASC;
```
