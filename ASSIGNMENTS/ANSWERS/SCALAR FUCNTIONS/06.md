# Assignment 06 — MySQL String Functions

## Scenario Overview
A customer relationship and HR operations team manages employee directory and contact records in MySQL. Due to manual entry from various sources, names have inconsistent casing, email addresses contain irregular capitalization, notes have leading/trailing whitespace, and phone numbers require masking and formatting for privacy compliance.

Your task is to write MySQL queries leveraging string manipulation functions (`UPPER`, `LOWER`, `LENGTH`, `CHAR_LENGTH`, `CONCAT`, `CONCAT_WS`, `SUBSTRING`, `LEFT`, `RIGHT`, `LPAD`, `RPAD`, `TRIM`, `LTRIM`, `RTRIM`, `REPLACE`, `REVERSE`, `INSTR`, `LOCATE`, and `REPEAT`) to clean, transform, format, and extract text data.

---

## Table Structure & Setup

### 1. Create Table: `employee_directory`
```sql
CREATE TABLE employee_directory (
    emp_id INT PRIMARY KEY AUTO_INCREMENT,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    phone_number VARCHAR(20) NOT NULL,
    city VARCHAR(50) NOT NULL,
    job_title VARCHAR(50) NOT NULL,
    notes VARCHAR(255) NULL
);
```

## Solutions to Assignment Questions

### 1. Case Conversion Functions

#### Q1. UPPER() / UCASE() — Full Name Uppercase
**Problem Statement:**
Display the employee's first and last name concatenated in all **UPPERCASE** letters.

```sql
SELECT 
    emp_id,
    UPPER(CONCAT(first_name, ' ', last_name)) AS uppercase_full_name
FROM employee_directory;
```

---

#### Q2. LOWER() / LCASE() — Standardize Email
**Problem Statement:**
Standardize all email addresses by converting them entirely to **LOWERCASE**.

```sql
SELECT 
    emp_id,
    first_name,
    email AS original_email,
    LOWER(email) AS standardized_email
FROM employee_directory;
```

---

### 2. Length Functions

#### Q3. LENGTH() vs CHAR_LENGTH() — Name Length
**Problem Statement:**
Display each employee's first name, the byte length using `LENGTH()`, and the character count using `CHAR_LENGTH()`.

```sql
SELECT 
    first_name,
    LENGTH(first_name) AS byte_length,
    CHAR_LENGTH(first_name) AS char_length
FROM employee_directory;
```

---

### 3. Concatenation Functions

#### Q4. CONCAT() — Full Name with Job Title
**Problem Statement:**
Combine `first_name`, `last_name`, and `job_title` into a single descriptive string formatted like:  
`"Aarav Sharma (Software Engineer)"`.

```sql
SELECT 
    emp_id,
    CONCAT(first_name, ' ', last_name, ' (', job_title, ')') AS employee_profile
FROM employee_directory;
```

---

#### Q5. CONCAT_WS() — Formatted Address/Contact Card
**Problem Statement:**
Use `CONCAT_WS()` with a comma separator `', '` to display `first_name`, `last_name`, `city`, and `phone_number`.

```sql
SELECT 
    emp_id,
    CONCAT_WS(', ', first_name, last_name, city, phone_number) AS contact_card
FROM employee_directory;
```

### 4. Substring & Extraction Functions

#### Q6. SUBSTRING() / SUBSTR() — Extract Username from Email
**Problem Statement:**
Extract the first 5 characters of each employee's `first_name`.

```sql
SELECT 
    first_name,
    SUBSTRING(first_name, 1, 5) AS short_name
FROM employee_directory;
```

---

#### Q7. LEFT() — Area/Network Prefix
**Problem Statement:**
Extract the first 3 digits (the area/network code) of each employee's `phone_number` using `LEFT()`.

```sql
SELECT 
    first_name,
    phone_number,
    LEFT(phone_number, 3) AS network_prefix
FROM employee_directory;
```

---

#### Q8. RIGHT() — Last 4 Digits for Verification
**Problem Statement:**
Extract the last 4 digits of each employee's `phone_number` using `RIGHT()`.

```sql
SELECT 
    first_name,
    phone_number,
    RIGHT(phone_number, 4) AS last_four_digits
FROM employee_directory;
```

---

### 5. Padding Functions

#### Q9. LPAD() — Formatted Custom Employee Code
**Problem Statement:**
Generate a standardized 8-character employee code by prepending zeros to `emp_id` and prefixing `'EMP-'` (e.g., `emp_id = 1` becomes `'EMP-0001'`).

```sql
SELECT 
    emp_id,
    CONCAT('EMP-', LPAD(emp_id, 4, '0')) AS formatted_emp_code,
    first_name,
    last_name
FROM employee_directory;
```

---

#### Q10. RPAD() — Fixed Width Formatting
**Problem Statement:**
Format the `city` name to a fixed width of 12 characters, padded on the right with dots (`'.'`).

```sql
SELECT 
    emp_id,
    first_name,
    RPAD(city, 12, '.') AS padded_city
FROM employee_directory;
```

### 6. Whitespace Cleaning Functions

#### Q11. TRIM(), LTRIM(), RTRIM() — Cleaning Free-Text Notes
**Problem Statement:**
Demonstrate removing leading whitespace with `LTRIM()`, trailing whitespace with `RTRIM()`, and both sides with `TRIM()` on the `notes` column.

```sql
SELECT 
    emp_id,
    first_name,
    notes AS raw_notes,
    LTRIM(notes) AS left_trimmed,
    RTRIM(notes) AS right_trimmed,
    TRIM(notes) AS fully_cleaned_notes
FROM employee_directory;
```

### 7. Search & Replacement Functions

#### Q12. REPLACE() — Standardizing Phone Number Format
**Problem Statement:**
Replace all hyphens (`'-'`) in `phone_number` with spaces (`' '`).

```sql
SELECT 
    emp_id,
    first_name,
    phone_number AS original_phone,
    REPLACE(phone_number, '-', ' ') AS space_formatted_phone
FROM employee_directory;
```

---

#### Q13. INSTR() / LOCATE() — Find Position of '@' in Email
**Problem Statement:**
Find the numerical index position of the `'@'` character within the `email` column using `INSTR()` and `LOCATE()`.

```sql
SELECT 
    emp_id,
    email,
    INSTR(email, '@') AS at_position_instr,
    LOCATE('@', email) AS at_position_locate
FROM employee_directory;
```

Display the reversed version of each employee's `first_name`.

Generate a string of 5 stars (`'★'`) using `REPEAT()` as a badge for every active employee.

### 8. Advanced Practical Applications

#### Q16. Dynamic Domain Extraction (SUBSTRING + LOCATE)
**Problem Statement:**
Dynamically extract only the **domain name** from the `email` column (everything after the `'@'` character).

```sql
SELECT 
    emp_id,
    first_name,
    email,
    LOWER(SUBSTRING(email, LOCATE('@', email) + 1)) AS email_domain
FROM employee_directory;
```

---

#### Q17. Dynamic Username Extraction (SUBSTRING + LOCATE)
**Problem Statement:**
Dynamically extract only the **username** portion of each employee's `email` (everything before the `'@'` symbol).

```sql
SELECT 
    emp_id,
    first_name,
    email,
    LOWER(SUBSTRING(email, 1, LOCATE('@', email) - 1)) AS email_username
FROM employee_directory;
```

---

#### Q18. Phone Number Masking for Privacy Compliance
**Problem Statement:**
Mask the employee's phone number so only the first 3 digits and the last 4 digits are visible, with the middle digits masked as `'***'` (e.g., `'987-***-3210'`).

```sql
SELECT 
    emp_id,
    first_name,
    phone_number,
    CONCAT(LEFT(phone_number, 4), '***-', RIGHT(phone_number, 4)) AS masked_phone
FROM employee_directory;
```
