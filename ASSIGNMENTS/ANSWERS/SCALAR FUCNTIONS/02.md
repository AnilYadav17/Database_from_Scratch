# Assignment 02 — MySQL Type Conversion Functions

## Scenario Overview
A financial analytics company manages transactions, billing schedules, user registrations, and account balances using MySQL. Because data comes in from legacy flat files, API payloads, and external payment gateways, several columns contain mixed formats, text-based numbers, unformatted date strings, and floating-point representations.

The finance and compliance teams need reports requiring explicit and implicit type conversions (`CAST`, `CONVERT`, date/time parsing, and numeric coercion) to ensure mathematical accuracy and standardized data formats.

---

## Table Structure & Setup

### 1. Create Table: `transaction_records`
```sql
CREATE TABLE transaction_records (
    transaction_id VARCHAR(20) PRIMARY KEY,
    customer_name VARCHAR(50) NOT NULL,
    amount_str VARCHAR(30) NOT NULL,
    discount_pct DECIMAL(5,2),
    tx_date_text VARCHAR(30) NOT NULL,
    created_timestamp DATETIME NOT NULL,
    status_code VARCHAR(5) NOT NULL
);
```

## Solutions to Assignment Questions

### Explicit Numeric & String Conversions

#### Q1. CAST() to SIGNED Integer
**Problem Statement:**
The finance team needs the transaction amounts as signed integer values (rounded/truncated as integer) for a high-level summary report. Convert `amount_str` into a `SIGNED` integer using `CAST()`.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    amount_str,
    CAST(amount_str AS SIGNED) AS amount_signed
FROM transaction_records;
```

---

#### Q2. CONVERT() to DECIMAL(10,2)
**Problem Statement:**
The compliance system requires the string amount `amount_str` to be explicitly converted into a `DECIMAL(10,2)` numerical value using `CONVERT()`.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    amount_str,
    CONVERT(amount_str, DECIMAL(10,2)) AS amount_decimal
FROM transaction_records;
```

---

#### Q3. CAST(... AS CHAR) for String Concatenation
**Problem Statement:**
To generate a plain text invoice log, display `transaction_id`, `customer_name`, and `discount_pct` joined together as a single string column formatted like:
`TXN-1001 : Rahul Sharma : 5.50`
Ensure the numeric `discount_pct` column is safely converted to character data using `CAST(... AS CHAR)`.

```sql
SELECT 
    CONCAT(
        transaction_id, ' : ', 
        customer_name, ' : ', 
        IFNULL(CAST(discount_pct AS CHAR), '0.00')
    ) AS invoice_log
FROM transaction_records;
```

### Date & Time Type Conversions

#### Q4. STR_TO_DATE() Text Date Conversion
**Problem Statement:**
The `tx_date_text` column stores dates as string text in the format `DD/MM/YYYY` (e.g., `'15/01/2025'`). Use `STR_TO_DATE()` to convert this text column into a valid MySQL `DATE` type.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    tx_date_text,
    STR_TO_DATE(tx_date_text, '%d/%m/%Y') AS tx_date
FROM transaction_records;
```

---

#### Q5. CAST() DATETIME to DATE
**Problem Statement:**
Extract and display only the date portion (`YYYY-MM-DD`) from `created_timestamp` by explicitly casting `created_timestamp` as a `DATE` type.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    created_timestamp,
    CAST(created_timestamp AS DATE) AS registration_date
FROM transaction_records;
```

---

#### Q6. DATE_FORMAT() for Formatted Readable Date
**Problem Statement:**
Format the `created_timestamp` column into a readable text date string in the format `"15th January 2025"` using date-to-string formatting functions.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    created_timestamp,
    DATE_FORMAT(created_timestamp, '%D %M %Y') AS formatted_date
FROM transaction_records;
```

---

#### Q7. STR_TO_DATE() + DAYNAME()
**Problem Statement:**
Convert the `tx_date_text` column into a standard `DATE` format, and then display the day of the week (e.g., `'Wednesday'`, `'Thursday'`) on which each transaction occurred.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    tx_date_text,
    STR_TO_DATE(tx_date_text, '%d/%m/%Y') AS tx_date,
    DAYNAME(STR_TO_DATE(tx_date_text, '%d/%m/%Y')) AS day_of_week
FROM transaction_records;
```

---

#### Q8. Substring Extraction & CAST() to UNSIGNED
**Problem Statement:**
Extract the numerical sequence from `transaction_id` (e.g., extract `'1001'` from `'TXN-1001'`) and explicitly convert it into an `UNSIGNED` integer.

```sql
SELECT 
    transaction_id,
    CAST(SUBSTRING_INDEX(transaction_id, '-', -1) AS UNSIGNED) AS numeric_sequence
FROM transaction_records;
```

#### Q9. CASE / IF on Text Status Code
**Problem Statement:**
The column `status_code` stores active status as string `'1'` and inactive status as `'0'`. Write a query using `CASE` or `IF` that evaluates `status_code` and displays `'Active'` for `'1'` and `'Inactive'` for `'0'`.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    status_code,
    CASE status_code
        WHEN '1' THEN 'Active'
        WHEN '0' THEN 'Inactive'
        ELSE 'Unknown'
    END AS status_display
FROM transaction_records;
```

#### Q10. Net Transaction Amount Calculation with Type Coercion
**Problem Statement:**
Calculate the net transaction amount after applying `discount_pct`. Since `amount_str` is stored as a string, perform the necessary explicit type conversion to calculate:
`Net Amount = Amount - (Amount * Discount / 100)`
Treat `NULL` discount values as `0%`.

```sql
SELECT 
    transaction_id, 
    customer_name, 
    amount_str,
    discount_pct,
    ROUND(
        CONVERT(amount_str, DECIMAL(10,2)) - 
        (CONVERT(amount_str, DECIMAL(10,2)) * IFNULL(discount_pct, 0.00) / 100), 
        2
    ) AS net_amount
FROM transaction_records;
```
