# Assignment 04 — MySQL NULL Handling Functions

## Scenario Overview
You are working as a **Data Analyst** for an e-commerce company. The company maintains employee sales and performance records. Due to incomplete data entry, some fields contain `NULL` values or `0` values. 

Your task is to write MySQL queries to generate different reports while correctly handling these missing values using `IFNULL()`, `COALESCE()`, and `NULLIF()`.

---

## Table Structure & Setup

### 1. Create Table: `employee_performance`
```sql
CREATE TABLE employee_performance (
    employee_id INT PRIMARY KEY,
    employee_name VARCHAR(50) NOT NULL,
    department VARCHAR(30) NOT NULL,
    salary DECIMAL(10,2) NOT NULL,
    bonus DECIMAL(10,2) NULL,
    sales_amount DECIMAL(12,2) NULL,
    commission DECIMAL(10,2) NULL,
    target_amount DECIMAL(12,2) NULL,
    email VARCHAR(100) NULL,
    alternate_email VARCHAR(100) NULL
);
```

## Solutions to Assignment Questions

### Q1 — Employee Earnings (IFNULL)
**Problem Statement:**
The HR department wants to calculate the **total earnings** of every employee:
`Total Earnings = Salary + Bonus + Commission`
If `bonus` or `commission` is `NULL`, consider it as **0**.

Display: `employee_id | employee_name | salary | bonus | commission | total_earnings`

```sql
SELECT 
    employee_id,
    employee_name,
    salary,
    bonus,
    commission,
    salary + IFNULL(bonus, 0) + IFNULL(commission, 0) AS total_earnings
FROM employee_performance;
```

---

### Q2 — Employee Contact Information (COALESCE)
**Problem Statement:**
The HR department needs **one available email address** for every employee:
* If primary `email` is available, display it.
* If primary `email` is `NULL`, use `alternate_email`.
* If both are `NULL`, display `'NO CONTACT AVAILABLE'`.

Display: `employee_id | employee_name | contact_information`

```sql
SELECT 
    employee_id,
    employee_name,
    COALESCE(email, alternate_email, 'NO CONTACT AVAILABLE') AS contact_information
FROM employee_performance;
```

---

### Q3 — Sales Target Calculation (IFNULL + NULLIF)
**Problem Statement:**
Management wants to calculate the percentage of the sales target achieved by each employee:
`Achievement Percentage = (Sales Amount / Target Amount) × 100`

Rules:
* If `sales_amount` is `NULL`, consider it as **0**.
* If `target_amount` is `NULL` or `0`, the calculation should return `NULL`.
* The query must not produce a **division-by-zero error**.

Display: `employee_id | employee_name | sales_amount | target_amount | achievement_percentage`

```sql
SELECT 
    employee_id,
    employee_name,
    sales_amount,
    target_amount,
    ROUND((IFNULL(sales_amount, 0) / NULLIF(target_amount, 0)) * 100, 2) AS achievement_percentage
FROM employee_performance;
```

### Q4 — Commission Percentage (IFNULL + NULLIF)
**Problem Statement:**
The Finance Department wants to calculate the percentage of commission earned by each employee based on their sales:
`Commission Percentage = (Commission / Sales Amount) × 100`

Rules:
* If `commission` is `NULL`, consider it as **0**.
* If `sales_amount` is `NULL` or `0`, the calculation should return `NULL`.
* The query must not produce a **division-by-zero error**.

Display: `employee_id | employee_name | sales_amount | commission | commission_percentage`

```sql
SELECT 
    employee_id,
    employee_name,
    sales_amount,
    commission,
    ROUND((IFNULL(commission, 0) / NULLIF(sales_amount, 0)) * 100, 2) AS commission_percentage
FROM employee_performance;
```

---

### Q5 — Combined NULL Handling ⭐ (COALESCE + IFNULL)
**Problem Statement:**
The HR department wants a report containing:
`employee_id | employee_name | contact_information | bonus_amount`

Rules:
* For `contact_information`: Use primary email if available; if `NULL`, use alternate email; if both are `NULL`, display `'NO CONTACT AVAILABLE'`.
* For `bonus_amount`: If `bonus` is `NULL`, display **0** instead.

```sql
SELECT 
    employee_id,
    employee_name,
    COALESCE(email, alternate_email, 'NO CONTACT AVAILABLE') AS contact_information,
    IFNULL(bonus, 0) AS bonus_amount
FROM employee_performance;
```
