## Table Structure & Setup

### 1. Create Table: `staff`
```sql
CREATE TABLE staff (
    staff_id INT PRIMARY KEY AUTO_INCREMENT,
    staff_name VARCHAR(50) NOT NULL,
    department VARCHAR(30) NOT NULL,
    city VARCHAR(30) NOT NULL,
    salary DECIMAL(10,2) NOT NULL,
    experience INT NOT NULL,
    age INT NOT NULL,
    email VARCHAR(100) NULL,
    phone VARCHAR(15) NULL,
    bonus DECIMAL(10,2) NULL,
    status VARCHAR(20) NOT NULL
);
```

## Solutions to Assignment Questions

### Q1. IF() — Salary Status
**Problem Statement:**
Display `staff_name`, `salary`, and salary status. If salary is ₹60,000 or more, show `'High Salary'`, otherwise `'Low Salary'`.

```sql
SELECT 
    staff_name, 
    salary,
    IF(salary >= 60000, 'High Salary', 'Low Salary') AS salary_status
FROM staff;
```

---

### Q2. IF() — Experience Status
**Problem Statement:**
Display `staff_name` and experience status. If experience is 5 or more, show `'Experienced'`, otherwise `'Fresher'`.

```sql
SELECT 
    staff_name, 
    experience,
    IF(experience >= 5, 'Experienced', 'Fresher') AS experience_status
FROM staff;
```

---

### Q3. IFNULL() — Email Availability
**Problem Statement:**
Display `staff_name` and email. If email is NULL, display `'Email Not Available'`.

```sql
SELECT 
    staff_name,
    IFNULL(email, 'Email Not Available') AS email
FROM staff;
```

---

### Q4. COALESCE() — Contact Information Priority
**Problem Statement:**
Display `staff_name` and contact information. Give priority to `phone` → `email` → `'No Contact'`.

```sql
SELECT 
    staff_name,
    COALESCE(phone, email, 'No Contact') AS contact_information
FROM staff;
```

---

### Q5. NULLIF() — Salary Check
**Problem Statement:**
Display `staff_name` and salary. If salary is exactly ₹50,000, return `NULL`; otherwise return the actual salary.

```sql
SELECT 
    staff_name,
    NULLIF(salary, 50000.00) AS salary
FROM staff;
```

### Q6. CASE — Salary Category
**Problem Statement:**
Create a salary category:
* `salary >= 80,000` → `'High'`
* `salary >= 60,000` → `'Medium'`
* Otherwise → `'Low'`

```sql
SELECT 
    staff_name, 
    salary,
    CASE
        WHEN salary >= 80000 THEN 'High'
        WHEN salary >= 60000 THEN 'Medium'
        ELSE 'Low'
    END AS salary_category
FROM staff;
```

### Q7. CASE + AND/OR — Employee Category
**Problem Statement:**
Create an employee category:
* `IT` + `experience >= 5` → `'IT Experienced'`
* `Finance` + `salary >= 70,000` → `'Finance High Earner'`
* `HR` + `experience >= 3` → `'HR Experienced'`
* Otherwise → `'Other'`

```sql
SELECT 
    staff_name, 
    department, 
    experience, 
    salary,
    CASE
        WHEN department = 'IT' AND experience >= 5 THEN 'IT Experienced'
        WHEN department = 'Finance' AND salary >= 70000 THEN 'Finance High Earner'
        WHEN department = 'HR' AND experience >= 3 THEN 'HR Experienced'
        ELSE 'Other'
    END AS employee_category
FROM staff;
```
