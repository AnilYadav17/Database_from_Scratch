# Assignment 03 — ALTER Students Table

## QNO 3: ALTER Students Table

### Task

- Add a column `dob` with data type `DATE`.
- Rename column `phone` to `mobile_number`.
- Modify column `age` to `SMALLINT`.
- Drop column `email`.

---

## 1. Show Tables

```sql
SHOW TABLES;
```

## 2. Add `dob` Column

```sql
ALTER TABLE students
ADD COLUMN dob DATE;
```

## 3. Rename `phone` to `mobile_number`

```sql
ALTER TABLE students
CHANGE COLUMN phone mobile_number VARCHAR(15);
```

## 4. Modify `age` to `SMALLINT`

```sql
ALTER TABLE students
CHANGE COLUMN age age SMALLINT;
```

## 5. Drop `email` Column

```sql
ALTER TABLE students
DROP COLUMN email;
```

## 6. Describe Updated Table

```sql
DESC students;
```

## 7. Display Student Records

```sql
SELECT * FROM students;
```

## Final Result

- `dob` column added successfully.
- `phone` renamed to `mobile_number`.
- `age` modified from `INT` to `SMALLINT`.
- `email` column dropped successfully.
- The `students` table now contains **7 columns**.
