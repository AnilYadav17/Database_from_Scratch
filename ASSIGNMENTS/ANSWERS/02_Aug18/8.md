# Assignment 08 — Employees Table

## QNO 8: Create and Insert into `employees` Table

### Task

Create an `employees` table and insert 5 employee records.

---

## 1. Create Employees Table

```sql
CREATE TABLE employees (
    emp_id INT,
    emp_name VARCHAR(100),
    gender VARCHAR(10),
    dob DATE,
    department VARCHAR(100),
    position VARCHAR(100),
    salary DECIMAL(8,2),
    joining_date DATE,
    phone VARCHAR(15)
);
```
