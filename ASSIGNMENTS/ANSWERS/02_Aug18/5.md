# Assignment 05 — TRUNCATE Table

## QNO 5: TRUNCATE Students Table

### Task

Remove all records from the `students` table using the `TRUNCATE` command.

---

## 1. Truncate Students Table

```sql
TRUNCATE TABLE students;
```

## 2. Display Student Records

```sql
SELECT * FROM students;
```

## Final Result

- All records from the `students` table were removed successfully.
- The table structure remains unchanged.
- `TRUNCATE` removes all rows from the table.
