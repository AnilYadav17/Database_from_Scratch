# Assignment 01 — Student Database

## 1. Login to MySQL

```bash
mysql -u root -p
```

## 2. Create Database

```sql
CREATE DATABASE 18Aug;
```

## 3. Select Database

```sql
USE 18Aug;
```

## 4. Create Student Table

```sql
CREATE TABLE students(
    id INT,
    name VARCHAR(100),
    age INT,
    gender VARCHAR(10),
    address VARCHAR(150),
    phone VARCHAR(15),
    email VARCHAR(100)
);
```

## 5. Describe Student Table

```sql
DESC students;
```

## 6. Insert First Student Record

```sql
INSERT INTO students
VALUES (101, "Anil", 21, "Male", "Dewas", 98765, "anil@gmail.com");
```
