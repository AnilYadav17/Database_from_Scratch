# Assignment 02 — Book Database

## 1. Create Book Table

```sql
CREATE TABLE book (
    book_id INT,
    title VARCHAR(150),
    author VARCHAR(100),
    genre VARCHAR(50),
    publication_year INT,
    price DECIMAL(6,2),
    publisher VARCHAR(100)
);
```
