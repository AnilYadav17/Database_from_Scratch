# Assignment 09 — Movie Reviews Table

## QNO 9: Create and Modify `movie_reviews` Table

### Task

Create a `movie_reviews` table, insert movie review records, modify the table using `ALTER`, `RENAME`, `TRUNCATE`, and `DROP` operations, and perform insert operations at different stages.

---

## Initial Table Creation

### 1. Create `movie_reviews` Table

```sql
CREATE TABLE movie_reviews (
    review_id INT,
    movie_title VARCHAR(150),
    reviewer_name VARCHAR(100),
    rating DECIMAL(2,1),
    review_text TEXT
);
```
