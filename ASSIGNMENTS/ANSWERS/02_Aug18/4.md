# Assignment 04 — Rename Table

## QNO 4: Rename `book` Table

### Task

Rename the `book` table to `library_books`.

---

## 1. Rename Table

```sql
ALTER TABLE book
RENAME TO library_books;
```

## 2. Show Tables

```sql
SHOW TABLES;
```

## Final Result

- `book` table renamed successfully to `library_books`.
- Database now contains the `library_books` and `students` tables.
